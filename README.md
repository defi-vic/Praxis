# Praxis

### Your teaching. Intelligently amplified.

Praxis is an AI-powered educational platform that helps teachers deliver more personalized learning without adding more work to their day.

Instead of replacing teachers, Praxis learns how a teacher teaches, understands where individual students struggle, and uses that context to help personalize instruction.

## The Problem

Every student learns differently, but teachers often have limited time to adapt their instruction to every student's needs.

Praxis helps bridge that gap by combining:

- Teacher teaching style
- Teaching materials
- Student learning patterns
- AI-powered analysis
- Personalized interventions

## How Praxis Works

### 1. Learn the Teacher
Praxis analyzes teaching materials to build a Teaching DNA a representation of how the teacher explains concepts, uses analogies, asks questions, gives examples, and structures lessons.

### 2. Understand the Student
Praxis tracks learning signals such as mastery, misconceptions, and responses to questions.

### 3. Personalize Instruction
Praxis Twin combines the teacher's Teaching DNA with the student's learning context to generate personalized explanations in the teacher's teaching style.

### 4. Close the Loop
After a student responds, Praxis evaluates the response, updates the learning signal, and generates insights and recommended interventions for the teacher.

## Core Features

- Teaching DNA
- Praxis Twin
- Praxis Insights
- Personalized student learning
- Teaching material analysis
- Adaptive learning signals

## Example

A Biology teacher uploads a lesson on Cellular Respiration.

Praxis learns the teacher's instructional style.

A student struggles with ATP.

Praxis identifies the misconception and generates an explanation adapted to both:

the teacher's teaching style + the student's learning needs.

The student's response then becomes a new learning signal that helps Praxis determine what should happen next.
